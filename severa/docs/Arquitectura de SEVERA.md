**Arquitectura de SEVERA**

SEVERA usa la arquitectura `Cliente-Servidor` para distinguir entre Frontend (`Cliente`) y Backend (`Servidor`).

# I. Backend 

La aplicación usa la `Arquitectura Hexagonal` para organizar los elementos en el Backend.

La propuesta para reestructurar el Backend actual incluye elementos de la Arquitectura Vertical Slicing pero aplicada a cada capa o separación logica propia de la Arquitectura Hexagonal.
