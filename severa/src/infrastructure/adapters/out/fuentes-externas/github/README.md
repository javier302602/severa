# fuentes-externas/github

El documento de arquitectura reserva esta carpeta "si aplica" (sección III/VI) para un adaptador normal (sin sistema de plugins, igual que `nvd/`) que sincronice datos desde GitHub. Hoy SEVERA no tiene ningún cliente ni adaptador de GitHub — la única fuente externa implementada es NVD (`fuentes-externas/nvd/`).

Carpeta reservada para cuando exista una integración real con GitHub.
